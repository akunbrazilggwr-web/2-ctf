CTF WEB — PIJAT NYAMAN
========================

Tujuan:
Temukan flag rahasia dan buktikan bahwa kamu bisa menemukan jalur menuju panel pengelola.

Batasan:
- Hanya boleh membaca berkas.
- Boleh memakai View Source.
- Tidak boleh DevTools.
- Tidak boleh scanner otomatis.
- Tidak perlu internet.
- Semua bahan CTF tersedia di paket ini.

Petunjuk umum:
1. Tidak semua halaman penting terlihat dari menu.
2. Beberapa nama berkas sengaja dibuat seperti halaman biasa.
3. Ada umpan.
4. Flag final berada langsung di HTML dashboard, bukan di berkas eksternal.
5. Jangan mencari kata "flag" saja. Cari jalurnya.

Tema: layanan pijat "Pijat Nyaman".
